# 🚲 Pedal Livre — Loja de Bicicletas

Site de uma loja de bicicletas feito com **React** (Vite), **HTML**, **CSS** e **JavaScript**.

## Funcionalidades

- Catálogo de bicicletas com filtro por categoria, busca e ordenação
- Carrinho de compras lateral (salvo no `localStorage`)
- Seções de serviços e formulário de contato
- Layout responsivo com menu mobile

## Como rodar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## Deploy

Hospedado na [Vercel](https://vercel.com) (framework: Vite, comando de build `npm run build`, pasta de saída `dist`).
